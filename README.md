# Safekeeper

Back up your folders and get them back.

## What it does

- Choose folders to back up and where to save them: an SD card, USB drive, or a cloud folder such as Google Drive.
- **Snapshots** save complete, timestamped ZIPs with checksums and keep the newest few. **Mirror** keeps one copy that matches your folders and copies only what changed.
- Run on demand or every day or week, optionally only while charging or on Wi-Fi. You get a notification when it's done.
- Verify any snapshot's checksums, browse it, and restore everything or just the files you pick. Restores never overwrite: existing names get "(restored)".
- Safekeeper can't back up other apps' private data or Android itself.
